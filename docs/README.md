## 今回の成果物

- ローカル Git リポジトリと `main` ブランチの初回コミット。
- `src/` に、HTTP サーバーで表示できる初期画面。
- 本フォルダの仕様・方針・公開手順・実装計画。
- `src/` だけをアップロードする、手動起動の GitHub Actions 設定。

ゲーム機能の実装は次段階です。GitHub 上のリポジトリ作成や公開設定はまだ行っていません。
公開先の GitHub アカウント／リポジトリ名、独自ドメイン、ソースコードのライセンスは未決定です。
初期段階では外部ライブラリ・画像・フォントを使用せず、独自ドメインも前提にしません。
