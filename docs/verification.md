## ローカルの実ブラウザー

Chromium 140.0.7339.16（Linux、headless）と、一時 HTTP サーバーの `/free-freecell/` 配信で検証しました。
再現用スクリプトは `scripts/browser-check.mjs` です。対応する Chromium を用意し、必要なら `CHROMIUM_BIN` を指定して `npm run test:browser` を実行します。

- 幅 320・768・1280px、日本語とスート表示、ページ全体の横はみ出しなし。狭い画面では盤面内を横スクロール。
- Enter／Escape とフォーカス、選択、合法・不正な移動、Undo／Redo と履歴分岐。
- 2 枚の連続したカードをまとめて選択・移動し、1 回の Undo で戻る。
- 再開始・新規ゲームの確認とキャンセル、時間の開始、勝利と取り消し。
- 実際に別タブへ切り替えて非表示にすると時計と保存時間が止まり、元のタブへ戻ると再開する。
- 保存の再読み込み、壊れた JSON、保存禁止でもプレイ継続。
- 合法な履歴から作った 19 枚の長い列と、CDP のタッチ入力による操作。
- CSS だけを変えた新版の取得・待機、旧版の対局維持、ブラウザープロセス再起動後の更新と進行保持。
- 配信サーバーを停止し、ブラウザープロセスも終了してから再起動して、オフラインでの復元・Undo／Redo・新規ゲーム。

ローカル HTTP サーバーで取得したレスポンス本文を計測した結果です。圧縮なしで、HTTP ヘッダー・TLS・ブラウザー自身の通信は含めません。

| 条件 | HTTP 要求数 | 本文の合計 |
| --- | ---: | ---: |
| 初回取得とオフライン準備完了 | 7 | 40,241 バイト |
| 変更のない直後の再訪 | 0 | 0 バイト |
| その後のブラウザー標準の SW 更新確認 | 1 | 4,609 バイト |

初回に同じファイルを二重取得せず、更新では変更のない JS を再利用しました。
ゲーム操作に伴うアプリのネットワーク取得はありません。Service Worker の標準の更新確認は起動に伴って発生するため、常に通信ゼロとする仕様ではありません。

## 検証の限界

Firefox・Safari・Edge、Android／iOS の実機での操作と、実スクリーンリーダーは未検証です。
ブラウザーの実際の 200% ズームは未検証で、画面幅を変えた確認とは区別します。
CDP によるタッチ操作は、実機の操作性を保証するものではありません。
キャッシュを消去・退避された端末、初回取得前、Service Worker を禁止した環境でのオフライン再起動は対象外です。
ゲームの保存が禁止されても、読み込み済みの画面でのプレイ継続は検証しています。
