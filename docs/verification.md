## 検証の限界

Firefox・Safari・Edge、Android／iOS の実機での操作と、実スクリーンリーダーは未検証です。効果音は API と波形を確認しましたが、実スピーカーでの聴感や端末音量ごとの聞こえ方は未確認です。
モバイル相当の標準ピンチは CDP の 2 本指入力で検証しました。デスクトップのメニューやキー操作による 200% ズームは未検証で、ピンチや画面幅を変えた確認とは区別します。
CDP によるタッチ操作は、実機の操作性を保証するものではありません。実機のアドレスバーが開閉するときの動的な表示高は未検証です。
横向きの低い画面で列が長い場合は、全体表示を優先して文字とタップ領域も小さくなります。844×390px の 19 枚列でも盤面全体は見えますが、縦向きほどの読みやすさはありません。
キャッシュを消去・退避された端末、初回取得前、Service Worker を禁止した環境でのオフライン再起動は対象外です。
ゲームの保存が禁止されても、読み込み済みの画面でのプレイ継続は検証しています。クリック更新を続ける間は旧版のキャッシュが端末に残る場合があり、旧タブがない次の有効化で整理します。ボタン導入前の旧版を最初に更新する際は、スーパーリロードかゲームのタブを閉じて開き直す操作が必要です。
